## Each Directory Has Its Own Packaging and Review; Keep the Endpoint Stable

Distribution through agents means ChatGPT app review, the Claude Connectors
directory, Cursor Marketplace, and other custom-connector lists, each wanting
slightly different assets, reviewer access, and update flows. Track the
requirements per destination, keep the endpoint URL stable across changes,
and test the experience after every change. It is closer to keeping a mobile
app healthy across OS versions and app stores than to maintaining an API.

For this app: a household server will not be listed anywhere at first, so
this rule is a reminder of the cost before deciding to publish.

Reference: Luca Rossi, Refactoring, 2026.
